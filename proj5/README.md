# Coffe chatbot

To run the bot, you need to install ollama and `llama3.2:3b` model. When ollama is installed (follow official documentation) you can run
```
ollama run llama3.2:3b
```
this will install and run the model. You can close it for now.

To talk with coffe chat:
```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```
